# Security

Node2Shell Radar discovers websites and reads public HTTP responses. **Active check** sends additional requests only when a user selects it. Radar does not send malformed Brotli streams or exploit payloads. A missing signal cannot establish that a site is safe, and a positive parsing signal cannot prove its patch state.

For a vulnerability in this tool, contact Secragon through [its vulnerability reporting page](https://secragon.com/security/). For CVE-2026-111497 itself, use the [Node.js security process](https://github.com/nodejs/node/blob/main/SECURITY.md).
