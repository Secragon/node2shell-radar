# Security

Node2Shell Radar performs asset discovery and passive HTTP inspection. It does not send malformed Brotli streams, run exploit payloads, or infer that a site is safe from a missing header. Some discovery options make additional DNS lookups or GET requests; the UI explains their impact before use.

For a vulnerability in this tool, contact Secragon through [its vulnerability reporting page](https://secragon.com/security/). For CVE-2026-111497 itself, use the [Node.js security process](https://github.com/nodejs/node/blob/main/SECURITY.md).
